# Submission Packaging Guide

## Prerequisites

1. Complete `TEAM_AND_REPOSITORY.txt` (no placeholders).
2. Prepare final PDF report path (optional but recommended).
3. Run full check successfully:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\scripts\full-check.ps1
```

Must show: **FULL PROJECT CHECK PASSED** (exit code 0).

## Package command

```powershell
.\scripts\package-submission.ps1 `
  -GroupNumber "XX" `
  -OutputDirectory ".\submission" `
  -ReportPath ".\docs\final-report.pdf"
```

## What the script does

1. Runs `scripts/full-check.ps1` — aborts if it fails.
2. Copies to a **temporary staging directory**:
   - `src`, `lib`, `scripts`, `examples`, `docs`
   - `README.md`, `ENVIRONMENT.md`, `TEAM_AND_REPOSITORY.txt`
   - `.vscode/settings.json`
3. Validates `TEAM_AND_REPOSITORY.txt` has no Arabic/English placeholders.
4. Validates report file is non-empty (if provided).
5. Excludes from ZIP: `out/`, `.venv/`, `__pycache__/`, `.pytest_cache/`.
6. Creates `Group-<GroupNumber>.zip` in the output directory.
7. Lists ZIP contents and deletes staging.

## What is NOT removed from your working copy

Staging is temporary; your local `out/`, `generated-app/`, etc. remain untouched.

## Included vs excluded

| Included | Excluded from ZIP |
|----------|-------------------|
| Source + grammars (.g4) | `out/` compiled classes |
| Scripts | `generated-app/.venv` |
| Examples + docs | pytest cache |
| ANTLR JAR in `lib/` | `sources.txt` |

`generated-app/` is **not** copied by default (regenerated by evaluator using scripts). Document this in your report if required by instructors.

## Placeholder check

Fails if `TEAM_AND_REPOSITORY.txt` contains:

- `[ضع الرابط هنا]`
- `[ضع رقم المجموعة هنا]`
- `[الاسم الأول]` … `[الاسم الرابع]`

Fill team data before packaging.
